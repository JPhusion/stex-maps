# STEX Maps

Mobile map of Space Tech Expo Europe 2026 (Messe Bremen, Halls 1 to 7).
Search exhibitors, see their booth, and get walking directions between any two booths.

Static site. Open `index.html` or serve with GitHub Pages.

- `map.webp`: floor plan rendered from the official hall plan PDF
- `data.js`: booth outlines plus a walkability grid used for routing
- `exhibitors.js`: exhibitor list from spacetechexpo-europe.com

Walking times assume about 1.1 m/s. Distances are estimated from Messe Bremen hall dimensions, so treat them as approximate.
